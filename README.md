# 中国国旗渐变头像生成器

China Flag Avatar Generator

一个简单的网页工具，可以为图片添加中国国旗风格的红色渐变和五星效果。

## 功能

- 上传 JPG / PNG / WebP 图片
- 左上角红色渐变效果
- 中国国旗五星叠加
- 调节红色强度
- 调节渐变范围
- 调节五星透明度
- 调节五星大小
- 调节五星间距
- 导出 PNG 图片

## 隐私

所有图片都在浏览器本地处理。

图片不会上传到任何服务器。

## 使用方法

1. 打开网页
2. 选择一张图片
3. 调节参数
4. 点击“下载处理后的图片”

## 技术

- HTML
- CSS
- JavaScript
- Canvas API
